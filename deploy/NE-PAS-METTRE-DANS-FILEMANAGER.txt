 ❌ NE METTEZ PAS CES FICHIERS / DOSSIERS DANS htdocs/
═══════════════════════════════════════════════════════════════════

Ces éléments viennent du dépôt GitHub ou de votre PC.
Ils ne servent PAS sur le site web et peuvent casser l'affichage :

  ❌ mobile-android/          → Projet APK (téléphone seulement)
  ❌ deploy/                  → Dossier de build sur GitHub
  ❌ nouvelle-eve-mobile.apk  → Application Android (pas pour le site)
  ❌ *.zip non extrait          → Le ZIP seul ne fait pas tourner le site
  ❌ .git/                      → Historique Git
  ❌ .gradle/                   → Fichiers de compilation Android
  ❌ node_modules/              → Si présent, inutile sur le serveur

 ✅ OBLIGATOIRE : config/config.php
═══════════════════════════════════════════════════════════════════

Le package contient seulement :
  config/config.example.php

Sans config/config.php, le site NE CHARGE PAS (page blanche ou erreur).

→ Si vous aviez déjà un site en ligne :
   NE SUPPRIMEZ PAS l'ancien config/config.php !
   Uploadez seulement les fichiers PHP mis à jour par-dessus.

→ Première installation (recommandé) :
   1. Uploadez et extrayez pharmagest-filemanager-complet.zip dans htdocs/
   2. Ouvrez https://votre-site.xo.je/setup.php
   3. Remplissez DB_HOST, DB_NAME, DB_USER, DB_PASS → Enregistrer

→ Alternative manuelle :
   1. Copiez config.example.php → config.php
   2. Éditez DB_HOST, DB_NAME, DB_USER, DB_PASS
