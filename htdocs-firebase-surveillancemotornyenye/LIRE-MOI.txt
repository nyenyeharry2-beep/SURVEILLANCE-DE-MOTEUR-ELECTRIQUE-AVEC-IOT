INSTALLATION
------------
1. File Manager → htdocs
2. Supprimez TOUS les anciens fichiers (main.js, mesure.php, app.css…)
3. Uploadez UNIQUEMENT index.html
4. Ctrl+F5 sur http://surveillancemotornyenye.xo.je/

------------------------------

- Cartes : État, RPM, Vibration, X/Y/Z
- Graphiques Chart.js temps réel

- Boutons ALLUMER / ÉTEINDRE → Firebase motor/command
