LUMEN — 3 etapes

1. File Manager : ouvrez le dossier htdocs
2. Upload & Unzip : envoyez TOUS les fichiers, y compris mesure.php
3. Ouvrez : http://VOTRE-DOMAINE/install.php
   puis http://VOTRE-DOMAINE/  (rafraîchir avec Ctrl+F5)
   Test API : http://VOTRE-DOMAINE/ping.php
              http://VOTRE-DOMAINE/mesure.php

Si « Identifiants incorrects » apparaît, renvoyez login.php, common.php,
config.php, api.js, main.js et index.html, puis relancez /install.php.

Si l’ESP32 affiche « Erreur POST mesure HTTP 404 » + page nginx :
  - l’URL doit être http://VOTRE-DOMAINE/mesure.php (avec .php)
  - pas un site Netlify (*.netlify.app)
  - mesure.php doit être dans htdocs (même dossier que index.html)
  - utilisez le sketch Lumen_ESP32/Lumen_ESP32.ino

Tableau de bord Firebase (Web/) ne reçoit pas les données ?
  1. L’ESP32 Lumen envoie vers mesure.php (MySQL), pas directement Firebase.
  2. Dans config.php, renseignez FIREBASE_DB_URL et FIREBASE_AUTH :
     mesure.php recopiera alors les mesures vers moteur/live.
  3. Dans Web/firebase-config.js, utilisez les MÊMES identifiants Firebase.
  4. Importez Firebase/seed_initial.json dans la console Firebase.
