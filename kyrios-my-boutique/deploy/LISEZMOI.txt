# 📦 KYRIOS MY BOUTIQUE — Fichiers à télécharger

## 1️⃣ BASE DE DONNÉES (phpMyAdmin)

**Fichier :** `kyriosboutique-database.sql`

### Comment importer :
1. Connectez-vous à **InfinityFree** → **MySQL Databases**
2. Cliquez sur **phpMyAdmin** pour la base `if0_42727746_kyriosboutique`
3. Onglet **Importer** → Choisir le fichier `kyriosboutique-database.sql`
4. Cliquez **Exécuter**

---

## 2️⃣ FICHIERS WEB (File Manager)

**Fichier :** `kyriosboutique-htdocs.zip`

### Comment installer :
1. InfinityFree → **File Manager** → ouvrir `htdocs`
2. Uploadez `kyriosboutique-htdocs.zip`
3. Clic droit → **Extract** (décompresser)
4. Vérifiez que `index.php` est à la racine de `htdocs`
5. Visitez : **https://kyriosboutique.page.gd**

> Le fichier `.env` est déjà configuré avec vos identifiants MySQL.

---

## 3️⃣ APPLICATION ANDROID

**Fichier :** `KyriosMyBoutique.apk`

### Comment installer :
1. Téléchargez l'APK sur votre téléphone Android
2. Autorisez **Sources inconnues** si demandé
3. Installez l'application
4. Ouvrez **Kyrios My Boutique**
