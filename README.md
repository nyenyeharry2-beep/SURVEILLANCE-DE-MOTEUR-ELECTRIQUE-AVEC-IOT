Ce dépôt contient plusieurs projets.

## FULL GOSPEL SMS (Application mobile)

Application Android Flutter pour envoyer des SMS via l'API du compte Full Gospel.

- **Code source** : [`full_gospel_sms/`](full_gospel_sms/)
- **APK prêt à installer** : [`releases/full-gospel-sms-v1.0.0.apk`](releases/full-gospel-sms-v1.0.0.apk)

### Installation rapide

1. Téléchargez l'APK depuis le dossier `releases/`
2. Transférez-le sur votre téléphone Android
3. Autorisez l'installation depuis des sources inconnues
4. Installez et ouvrez **FULL GOSPEL SMS**

### Fonctionnalités

- Consultation du solde de crédits SMS
- Envoi de SMS avec l'expéditeur **FULL GOSPEL**
- Import de contacts
- Historique des messages envoyés

Voir [`full_gospel_sms/README.md`](full_gospel_sms/README.md) pour les instructions de développement.
