JOYCE 1 — INFINITYFREE (File Manager → htdocs)
==============================================

Tout le site tourne sur InfinityFree (otornyenye.rf.gd). Pas de Netlify.

ÉTAPES — JOYCE 1 (racine htdocs)
--------------------------------
1. File Manager → dossier htdocs
2. Téléversez TOUS les fichiers de « joyce 1 » à la racine de htdocs
3. Ouvrez : http://otornyenye.rf.gd/install.php
4. Puis : http://otornyenye.rf.gd/
5. Tests :
   http://otornyenye.rf.gd/ping.php
   http://otornyenye.rf.gd/mesure.php

ÉTAPES — JOYCE 2 (sous-dossier firebase)
----------------------------------------
1. Dans htdocs, créez le dossier : firebase
2. Téléversez TOUS les fichiers de « joyce 2 » dans htdocs/firebase/
3. Ouvrez : http://otornyenye.rf.gd/firebase/

Deux tableaux de bord :
  http://otornyenye.rf.gd/           → Lumen (connexion PHP)
  http://otornyenye.rf.gd/firebase/  → Firebase (graphiques temps réel)

FICHIER IMPORTANT : config.php (racine htdocs)
----------------------------------------------
  DB_PASS          → mot de passe MySQL InfinityFree
  DEVICE_KEY       → lumen-esp32-nyenye-7f3a9c (identique à l’ESP32)
  FIREBASE_DB_URL  → URL Realtime Database
  FIREBASE_AUTH    → secret legacy Firebase

Exemple :
  define('FIREBASE_DB_URL', 'https://VOTRE-PROJET-default-rtdb.europe-west1.firebasedatabase.app');
  define('FIREBASE_AUTH', 'VOTRE_SECRET_ICI');

Sans FIREBASE_DB_URL, le site Lumen fonctionne mais /firebase/ restera vide.
