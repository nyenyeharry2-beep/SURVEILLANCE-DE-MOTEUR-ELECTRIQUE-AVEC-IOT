NYENYE — Surveillance moteur (Firebase + interface complète)
============================================================

DOMAINE : http://surveillancemotornyenye.xo.je/

FICHIERS htdocs (tous obligatoires)
-----------------------------------
index.html
main.js
firebase-api.js
firebase-config.js
app.css
calculs.js

INSTALLATION
------------
1. Supprimez les anciens fichiers PHP/Lumen (mesure.php, config.php, etc.)
2. Uploadez TOUS les fichiers ci-dessus dans htdocs
3. Ouvrez http://surveillancemotornyenye.xo.je/  (Ctrl+F5)

FONCTIONNALITÉS
---------------
- Vue d'ensemble, Surveillance, Historique, Diagnostic, Commande moteur
- Graphiques temps réel (Chart.js)
- Boutons ALLUMER / ÉTEINDRE → Firebase motor/command
- Données en direct depuis Firebase motor/live
- Badge « Firebase connecté » (pas MySQL)

FIREBASE
--------
Projet : surveillance-moteur-f38e1
motor/live       ← ESP32 envoie vib, rpm, motorOn, alert…
motor/command    ← commandes web
motor/thresholds ← seuils vibMax / rpmMax

ESP32 : sketch Firebase → motor/live (pas mesure.php)
