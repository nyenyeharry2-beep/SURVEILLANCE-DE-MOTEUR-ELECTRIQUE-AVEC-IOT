# KYRIOS

Application de messagerie et réseau social — implémentation UI basée sur le cahier des charges.

## Fonctionnalités

- **Chats** — Liste de conversations avec stories, filtres (All, Favorites, Work, Groups), badges non-lus
- **Conversation** — Vue de chat groupe avec bulles glassmorphism, réactions, médias
- **Discover** — Fil d'actualité avec posts, stories et engagement
- **Communities** — Groupes thématiques
- **Profile** — Profil utilisateur avec stats, highlights et grille photos
- **Calls** — Historique d'appels

## Design

- Thème sombre glassmorphism (inspiré des maquettes KYRIOS)
- Interface mobile-first dans un cadre iPhone
- Navigation flottante en bas d'écran

## Démarrage

```bash
cd kyrios
npm install
npm run dev
```

Ouvrir [http://localhost:5173](http://localhost:5173)

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Lucide React (icônes)
