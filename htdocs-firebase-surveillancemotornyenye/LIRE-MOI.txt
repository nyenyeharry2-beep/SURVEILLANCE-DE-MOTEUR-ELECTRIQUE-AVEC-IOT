NYENYE — Surveillance moteur (Firebase)
========================================

DOMAINE : http://surveillancemotornyenye.xo.je/

INSTALLATION INFINITYFREE
-------------------------
1. File Manager → htdocs
2. Supprimez TOUS les anciens fichiers (Lumen, PHP, main.js, app.js…)
3. Uploadez index.html (ce fichier seul suffit)
4. Ouvrez http://surveillancemotornyenye.xo.je/

FIREBASE (déjà configuré dans index.html)
-----------------------------------------
Projet : surveillance-moteur-f38e1
Chemins :
  motor/live       ← données ESP32
  motor/command    ← marche / arrêt / urgence
  motor/thresholds ← seuils vibMax / rpmMax

ESP32
-----
Doit publier vers motor/live (pas moteur/live, pas mesure.php)

FICHIERS htdocs
---------------
index.html   ← tout-en-un (HTML + CSS + JS + Firebase)
