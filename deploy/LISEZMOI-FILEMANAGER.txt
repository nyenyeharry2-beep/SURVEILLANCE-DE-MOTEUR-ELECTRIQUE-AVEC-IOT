═══════════════════════════════════════════════════════════════════
 ÉTAPE 1 — UPLOAD SUR INFINITYFREE
═══════════════════════════════════════════════════════════════════

1. Connectez-vous à InfinityFree → File Manager
2. Ouvrez le dossier htdocs/
3. Uploadez : pharmagest-filemanager-complet.zip
4. Clic droit → Extract (Extraire) DANS htdocs/ (pas dans un sous-dossier)
5. Vous devez obtenir DIRECTEMENT dans htdocs/ :
   htdocs/index.php
   htdocs/login.php
   htdocs/api/
   htdocs/includes/
   htdocs/vendeur/
   htdocs/assets/
   htdocs/config/
   htdocs/ventes.php, journal.php, caisse.php, etc.

   MAUVAIS (ne pas faire) :
   htdocs/pharmagest-filemanager-complet/login.php

6. Supprimez le .zip après extraction (optionnel)

⚠️ NE SUPPRIMEZ PAS config/config.php s'il existe déjà !
   (contient vos identifiants base de données)
   Si première installation (le plus simple) :
   - Ouvrez https://mapharmaciepk.xo.je/setup.php
   - Remplissez vos identifiants MySQL InfinityFree → Enregistrer
   Alternative manuelle :
   - Copiez config/config.example.php → config/config.php
   - Modifiez DB_HOST, DB_NAME, DB_USER, DB_PASS

 WORKFLOW QUOTIDIEN
═══════════════════════════════════════════════════════════════

1. MATIN (6h+) → Journal → Ouvrir journée (fond caisse + taux USD)
2. JOURNÉE → Vendeurs vendent (APK / PC / web)
3. SOIR (20h) → Clôturer journée (montant caisse)
4. APRÈS 20h → Nouveau jour métier → ouvrir nouvelle journée

Sans journée ouverte → ventes bloquées sur APK et portail PC.
