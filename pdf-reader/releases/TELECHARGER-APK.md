## Installation Android

1. Téléchargez le fichier `.apk`
2. Ouvrez **Fichiers** → **Téléchargements**
3. Appuyez sur `lumen-reader-debug.apk`
4. Autorisez **Installer des applications inconnues** si demandé
5. Appuyez sur **Installer**
