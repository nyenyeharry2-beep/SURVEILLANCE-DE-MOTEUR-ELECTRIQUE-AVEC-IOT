JOYCE 2 — TABLEAU DE BORD FIREBASE (InfinityFree uniquement)
=============================================================

Pas de GitHub. Pas de Netlify.
Téléversez avec le File Manager InfinityFree dans htdocs/firebase/

Où téléverser
-------------
1. File Manager → htdocs → créez le dossier firebase
2. Entrez dans firebase
3. Upload joyce 2.zip → Extract (ou fichier par fichier)
4. URL : http://otornyenye.rf.gd/firebase/

Structure sur le serveur :
  htdocs/
    index.html, mesure.php, config.php ...  ← joyce 1
    firebase/
      index.html, app.js, firebase-config.js ...  ← joyce 2

ÉTAPE 1 — Firebase Console (console.firebase.google.com)
--------------------------------------------------------
1. Realtime Database → Créer (mode test)
2. Données → Importer → seed_initial.json (ce dossier)
3. Règles → coller database.rules.json → Publier
4. Paramètres → App Web → copier apiKey, databaseURL, etc.

ÉTAPE 2 — firebase-config.js
----------------------------
File Manager → htdocs/firebase/firebase-config.js → Edit
Remplacez TOUS les VOTRE_… par vos clés Firebase.

ÉTAPE 3 — config.php (racine htdocs, joyce 1)
----------------------------------------------
  define('FIREBASE_DB_URL', 'https://...firebasedatabase.app');
  define('FIREBASE_AUTH', 'VOTRE_SECRET');

L’ESP32 → mesure.php → MySQL + copie Firebase moteur/live.

Vérification :
  http://otornyenye.rf.gd/firebase/
  Firebase Console → moteur/live (valeurs qui changent)
